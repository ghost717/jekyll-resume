# Terminal Resume

Przykładowe CV programisty Python/AI zbudowane w [Jekyll](https://jekyllrb.com/) przy użyciu motywu [hacked-jekyll](https://github.com/piazzai/hacked-jekyll).

## Uruchomienie lokalne

Wymagane są Ruby oraz Bundler.

```bash
bundle install
bundle exec jekyll serve --livereload
```

Strona będzie dostępna pod adresem <http://localhost:4000>.

## Personalizacja

- Dane CV znajdują się w `_data/json.yml`.
- Metadane strony i kolory motywu można zmienić w `_config.yml`.
- Dodatkowe style znajdują się w `_sass/_custom.scss`.

Treść jest fikcyjna i służy jako punkt startowy do przygotowania własnego CV.
